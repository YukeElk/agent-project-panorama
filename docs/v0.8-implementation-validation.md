## Browser interaction evidence

The generated local V0.8 candidate was exercised in the Codex in-app browser over `127.0.0.1`.

Observed results:

1. `SYSTEM` retains `全景查看 / 架构设计 Studio / 全景讲解` as peer modes; the guided surface is not an iframe, data URL, separate page, or modal replacement.
2. `全景讲解` exposes six chapter tabs and the three coordinated rails `逐步讲解 / 节点讲解 / 业务流程演示`.
3. Clicking a graph node immediately opens node explanation. `Business Agent` displayed the complete chain: design requirements, design reasons, implemented function, system role, interactions, technology selection, and related risks.
4. The canonical module drawer initially expands only `设计需求`; later design, role, interaction, technology, decision/risk, and raw evidence sections remain available on demand.

8. Four required desktop viewports (`1440×900`, `1600×1000`, `1920×1080`, `2048×1320`) exercised all six views with zero document overflow, node overlap, edge-through-node, side overflow, console warning, or console error.
