# V0.8 WP5 统一编辑画布验证

状态：WP5 专项实现与验证通过；不代表 WP6–WP8、发布或人工视觉接受完成

日期：2026-08-23

## 交付结论

Architecture Studio 已迁入 WP4 的唯一 Canvas Runtime。页面只保留 `read|edit` 两种模式；编辑模式复用同一 `CanvasSceneAdapter`、`CanvasStore`、`CameraController`、`NavigationStack` 与一个 `data-canvas-world="one"`。

- 架构主画布可编排 Layer、Module 与 Candidate Connection，并编辑层级名称、职责、顺序和父子关系；父子循环、含模块或子层的删除失败关闭。
- 双击 Module 进入其模块内部逻辑子画布；Current Observation 首次进入编辑时复制为隔离 Target Candidate，不修改正式 Current。
- 子画布可创建和修改 Logic Node、Logic Edge、Loop 退出条件与 Boundary Port；外部 Module 只投影只读引用卡。
- Module Logic 语义进入 Candidate Semantic Hash；节点/端口位置只进入 Layout Hash；Camera、Selection、Viewer State 和操作时间不进入语义正式化结果。
- Candidate 可确定性物化为正式 `architecture.moduleLogicDesigns[]`；草稿 ID 映射为稳定正式 ID，跨边界端口映射正式 Connection；`unbound_candidate` 和 stale Observation Binding 阻断正式化。
- 同一编辑栏恢复 Session CAS → Formal Validate → Codex Read-only Review → Proposal Freeze → Exact Hash Approval → Apply。离线页面正确禁用正式化动作。

## 真实浏览器验证

验证候选：`.panorama-work/v0.8-wp5-browser/unified-read-edit-module-logic.html`

结果：

1. Module 单击立即打开节点完整逻辑链，无需回车。
2. 阅读/编辑切换继续使用一个 Canvas World，画布 `overflow:hidden`，节点几何和 Camera Controller 未切换为滚动容器。
3. 编辑模式双击 Orchestrator 进入模块子画布；AI Current Observation 被复制为 2 个内部节点、1 个 Boundary Port 和 1 个外部模块引用的 Target Candidate。
4. 外部模块只显示引用卡，不展开其内部节点；单击内部节点可编辑设计需求、原因、实现逻辑、类型和 Loop 退出条件。
5. 父层级选择可修改并立即重绘；修复了初始 `parentLayerId` 缺失时对 `undefined` 深拷贝导致的浏览器异常。
6. 离线时正式校验、评审、提案、批准与 Apply 均禁用，并显示 Bridge 边界。
7. 修复后新页面 Browser Console 为 `[]`，无 Error/Warning。
