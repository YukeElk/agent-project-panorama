  supersede、Validator 与 pending recovery；

  `revoke_approval_policy.py`、`validate_approval_policy_store.py`：write-once 生命周期 CLI；

- `validate_governance_outbox.py`：Outbox Store 校验和显式恢复；
- `apply_patch.py --event-store [--outbox-store]`：opt-in fail-closed Proposal/Apply Event Capture。

## 6. 下一门禁

Approval Policy Core 与 `Proposal → Approval → Apply` Outbox Adapter 已满足上述门禁。下一切片只选择一个
低风险 Operation Adapter，建议优先 `engineering_event.record` 或 `event_head.recover`，并要求：

1. Adapter 先调用 Core 分配 Use，再执行精确 Operation，最后生成 Event + Receipt；
2. Policy expiry/use/source/project/binding/scope 任一失败不产生副作用；
3. Adapter 故障注入覆盖 pre-effect、post-effect、Event durable、Receipt durable 和 Ledger advance；
4. 不复用普通 Studio Proposal Approval，不扩大治理保护路径；
5. 完整回归继续保持绿色。

该门禁通过前，不并行接入多个 Operation Adapter，也不启动 Renderer、Projection 或 Export。
