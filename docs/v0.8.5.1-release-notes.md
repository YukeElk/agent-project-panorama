# V0.8.5.1 Release Notes

日期：2026-08-25

状态：**Approved Patch Release — external publication remains subject to automatic CI gates**

## 修复内容

- 新增证据绑定的 Architecture Layering Contract，固定结构字段但不固定层级分类法；
- 为 Architecture 增加兼容的 `layeringProfile`，为 Layer 增加 `layerSemantics`，为 Module 增加
  `layerAssignments`；
- 明确“架构层级/容器 → 功能模块 → 模块内部逻辑”三层颗粒度，避免把内部访问、预处理、Loop 等步骤错误提升为模块；
- 正式 Validator 检查 Layer Semantics、Assignment、Evidence、Confidence、未分配规则及正式 Binding 一致性；
- Studio 新建模块必须使用当前选择或显式 `LAYER-UNASSIGNED`，不再按模块类型、名称或 Layer 数组位置猜测；
- 跨层拖动和下拉换层同步失效旧归层依据，并把新理由、证据和置信度纳入 Candidate Semantic Hash；
- Model/View IR 保留 `parentLayerId/kind/layerSemantics` 与祖先 Group，空父容器不再被投影丢弃；
- Guided Host 显示完整父子层级路径，Reference HTML 同步当前 Renderer。

## DeepSeek Harness / BFF 类项目的行为

- 名称只能形成待验证假设，不能形成正式归层；
- Harness 是否为独立模块取决于执行生命周期、Loop、状态、工具调度、接口和独立演进证据；
- BFF 是否为独立模块取决于接入、安全、协议转换、部署和演进边界；若只是 Harness 内部适配步骤，则进入模块子画布；
- 证据无法消除歧义时使用 `LAYER-UNASSIGNED` 并记录候选 Layer，不静默拆分或合并。

## 保留边界

- V0.8.5.1 不修改 Panorama Core Schema 版本、Renderer `0.4.0`、Multistack Registry `0.85.0` 或各编译器协议版本；
- 不声称静态源码抽取已经理解运行调用、业务流程或完整模块内部逻辑；
- 不新增团队协作、RBAC、中央服务、Dataset/RAG/Eval Export；
- 不随本次 GitHub Release 自动晋升 Verified Delivery last-good。
