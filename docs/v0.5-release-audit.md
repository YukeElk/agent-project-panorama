# V0.5.0 Release Audit

日期：2026-08-20–21

审核对象：Engineering Event Foundation Slice A、Approval Policy Core，以及显式 opt-in 的
Proposal/Apply Governance Outbox。

## 结论

**本地与远程发布候选审核通过；允许创建 V0.5.0 Tag / Release。**

阻断发布的 P0/P1 代码问题已经修复并由负向测试覆盖。候选分支
`agent/v0.5-engineering-event-foundation` 已建立稳定提交身份；GitHub Actions
[`32389819872`](https://github.com/YukeElk/agent-project-panorama/actions/runs/32389819872) 的 Python 3.10、
Python 3.12、Linux 符号链接、Node、Reference、Receipt 与 Presentation Hash 门禁全部通过。

## 候选范围

V0.5.0 只包含：

1. Project-local Engineering Event Schema、Store、Validator、Head 与显式恢复；
2. Approval Policy Prepare、exact-hash Approval、Materialize、Activation、Use Ledger、Receipt/Event、
   Revocation、Supersede 与 Store Recovery；
3. 普通 Proposal/Apply 的显式 opt-in、fail-closed Governance Outbox。

Observation、Verification Receipt、Validation Manifest、Event Head、Verified Delivery、Renderer 与
Freshness 的 Delegated Policy Adapter，以及 View IR、Renderer 改版、Dataset/RAG/Eval Export、后训练和
Agent 平台均不属于本候选版本。

## 修复闭环

| 原问题 | 修复结果 | 验证 |
| --- | --- | --- |
| Protected Path 只匹配相同深度，可绕过后代路径 | Allow 仍精确匹配；Built-in/Forbidden 按受保护根覆盖全部后代 | `/intent/currentFocus` 与 Resource Credential 后代负向测试 |
| Receipt `not_applicable` 可绕过 Formal Validation | `requireFormalValidation=true` 时只接受 `passed` | 成功请求被确定性降级为失败且不写成功 Event |
| Outbox 终态未绑定完整性 | 新增覆盖完整 Outbox 状态的 canonical `stateHash`，每次合法转换重算 | 伪造 abandoned 终态被 `STATE_HASH` 拒绝 |
| Prepared/Approval 生命周期字段可伪造 | 校验 awaiting 状态、Validation、版本/Hash、Method、Time Source、时间顺序和身份 | rejected Prepared、invalid Validation、forged clock 全部拒绝 |
| Materialize 可能先激活后输出失败 | 先发布或精确复用 Active Artifact，再激活 Store | 注入激活失败后输出保留，精确重试成功 |
| Policy 激活中断产生 orphan ledger | 仅恢复精确绑定且完全未使用的初始 Ledger | 激活标记故障注入与恢复测试 |
| Pending Store Validator 返回成功 | 只有 valid 且无需恢复时退出 0 | Pending CLI 返回 1 |
| JSON 无嵌套上限 | Policy 与 Outbox 最大容器深度固定为 20 | 25 层输入在写入前拒绝 |
| Validation Lab 进入发布状态 | 根目录 `/validation-lab/` 已忽略 | `git status` 不再列出实验目录 |
| Python 3.10 缺少 `locale.getencoding` | 3.11+ 使用 `getencoding`，3.10 使用 `getpreferredencoding(False)` | 两条 API 路径均有自动测试 |

## 已知限制

- Hash 提供完整性检测，不提供外部签名或主机级防篡改；Store 访问控制仍由项目环境承担。
- Node 在本机不可用；Node 门禁已由远程 CI 补齐。
- Windows 当前环境无法创建测试符号链接；Linux CI 已实际执行该用例并通过。
- Governance Outbox 只有显式提供 Event Store 时启用；其他 Capture Adapter 未实现。
- Installed Skill 与正式 Git Release 尚未更新，不能把源码工作树状态视为已发布能力。
