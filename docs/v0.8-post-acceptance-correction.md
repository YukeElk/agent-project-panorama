# V0.8 验收后编辑模式修正

日期：2026-08-23

状态：代码修正与自动化回归完成；新浏览器证据、PVD 与人工视觉接受待完成；发布阻断

## 缺陷结论

用户在已接受候选 `PVD-72F0C8D96F8F6333F42B6790` 中报告的三个问题均成立：

1. 既有模块编辑器只暴露少量字段，离线 Studio Session 也没有复制完整 Target Design；
2. 拖动卡片时只修改节点 DOM 坐标，SVG 路径没有实时重算；
3. `layout-move` 只保存 `x/y`，没有命中层级、吸附边界或更新模块 `layerId`。

该 PVD 与 SHA-256 的原始人工接受保留为历史事实，但不再具备当前发布效力。

## 修正内容

- 既有模块现在可编辑中文主显示名、设计需求与用途、职责、非职责边界、状态所有权、处理数据、接口摘要、
  部署角色、技术选型和所属架构层；稳定技术名与正式 ID 保持只读。
- Studio Session 初始化与旧草稿恢复会补齐缺失的完整模块语义字段，同时保留用户已有草稿值。
- 拖动期间按节点实时尺寸重算相连 SVG 曲线；释放后路径与节点保持绑定。
- 架构主画布按卡片中心命中目标层级，显示投放高亮，释放时限制到层级边界内并将 `layerId` 作为语义变化记录。
- 同层移动只改变 Layout Hash；跨层吸附同时产生布局操作与 `node.layer.snap` 语义操作。
- Python 与浏览器侧候选 Diff 都纳入 `displayName`，完整编辑结果可物化回 Panorama Target Design。
