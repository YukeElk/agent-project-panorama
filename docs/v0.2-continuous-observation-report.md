# V0.2 Continuous Observation 实施报告

## 结论

V0.2 已建立单一正式全景的持续事实追踪：Current 可自动更新，Target、Decision、Review、
Acceptance、Waiver、Guidance、Credential、Schema 与 Policy 受保护。自动化不修改业务项目，
不向业务分支提交，也不替用户作决策。

- `panorama.schema.v0.2.json`：Observation Policy、Source Binding、Fact Provenance、Current
  Architecture Snapshot、Standard Assessment 与 Observation Batch；
- `standard-pack.schema.v0.1.json`：声明式项目规范；
- V0.1 → V0.2 新文件迁移；
- Commit/Merge/Checkout/Rewrite Hook、后台一次同步与 Skill 启动补偿；
- Policy Hash、受保护路径、Fact Class Allowlist、Revision/Data/HEAD 并发检查；
- Standard Pack 校验、安全路径解析和风险候选披露；
- Last Known Good 备份、独占锁、原子替换和 Presentation Hash 保持；
- Renderer 0.2.0 自动追踪状态披露，无新增主视图。

## 已知限制

- Hook 的确定性 Worker 自动更新结构化事实；需要 LLM 的深层架构重建必须由后续 Skill 调用产生
  fact-only Operations，再受同一 Policy 校验，不在 Hook 中无人值守调用模型/API；
- 自动发现不会把任意目录直接当 Module；新 Module 需要已授权 Agent 推断或未来的声明式 Module
  Binding 规则；
- Panorama-owned Git State Ref 结构已保留为策略选项，但本版默认关闭且未实现自动 Push；
- SF-03、SF-08、SF-09、SF-13 的完整架构版本快照、Artifact Manifest、结构化 Replacement 和
  Next Focus Snapshot 仍未实现。
