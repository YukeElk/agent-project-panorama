# V0.6 Multi-view Compiler Validation

日期：2026-08-21  
状态：WP3 Dependency/Data Flow + Deployment/Runtime 切片通过；尚未发布

## 1. 本轮范围

- Model IR 新增正式 Release、Deployment、Resource/Data Store 投影；
- 新增 Deployment → Release、Module → Deployment、Deployment → Resource 关系；
- 新增 `dependency_dataflow` 与 `deployment_runtime` View Compiler；
- View Group 从 Layer-only 扩展为显式 `layer/environment/source_kind`；
- View Validator 增加 profile/compiler、Node/Entity、Edge/Relation、relation kind、scope 与端点绑定；
- CLI 支持 module、dependency_dataflow、deployment_runtime 三种 profile。

本轮不包含 Sequence、Lifecycle、Evolution/Risk、Interactive Renderer、last-good 或公开发布。

## 2. 事实与安全边界

- 静态 dependency 不提升为 runtime call、data flow 或 sequence message；
- Deployment status 默认是 declared，不提升为 Observed Runtime；
- 任一 Deployment relation 未经 exact observed provenance 证明时，View 明示
  `deployment_runtime_observation_not_verified`；
- Resource Model attributes 不复制 Access/Credentials；
- Dependency 根遍历使用精确 Entity ID、最大深度和最大节点数，超限 fail closed；
- shared resource 作为真实 Relation 端点保留，不因 environment UI 分组而删除。

## 4. 负向门禁

- 未知/重复/out-of-scope root 拒绝；
- `maxDepth`、`maxNodes` 越界或全图超预算拒绝；
- 重算 Semantic Hash 后篡改 Node label 或 Compiler 仍拒绝；
- Relation kind 不属于 profile、端点不一致或 scope 不一致拒绝；
- 输出文件已存在且未显式 `--overwrite` 时拒绝。
