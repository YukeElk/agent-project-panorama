# Agent Project Panorama V0.7.0

V0.7.0 将项目全景从“可交互查看多种架构图”推进为“可按证据逐步讲解项目架构”，同时保持单一 Skill、
Codex 运行终端和 V0.6 数据合同兼容。

## 新增能力

- 从 Panorama Core、Model/View IR 与 Guided View Set 确定性编译 Explain Pack；
- 覆盖 Module、Dependency/Data Flow、Deployment/Runtime、Sequence、Lifecycle、Evolution/Risk 六类图；
- 增加 Decision、Transition、Evidence/Freshness 与 Verification Trace 讲解；
- 在 Codex 对话中输出无网络交互 Fragment，并提供 Markdown 降级；
- 在 Panorama Single HTML 中提供同源原生 Dialog、逐步聚焦、章节切换与键盘导航；
- 将 Explain Pack 的语义身份绑定到 Renderer Bundle 与 Verified Delivery Candidate；
- 对稀疏信息使用受约束的信息缺口叙述，不由模型自由补全架构事实。

## 验证

- 完整本地基线：419 passed，2 skipped；V0.7 聚焦测试：11 passed；
- Runtime Preflight：26 Schemas compatible，0 error；
- 五个 Proof Case，覆盖真实 Java、TypeScript/Backstage slice、治理型与 Event 型输入；
- Controlled Orders 代表包：17 Stories、48 Steps；
- 多尺寸真实浏览器检查：0 overflow、0 node overlap、0 edge-through-node、0 console error；
- 精确 Verified Delivery、Explain Pack、Bundle 与 Artifact SHA-256 绑定。

## 明确边界

Visualize 是可选展示能力，不是 Skill 的运行时硬依赖；本版本不复制插件实现，不引入云端后端、通用 Agent
平台、Dataset/RAG/Eval Export 或模型后训练。讲解不是新的事实源，Decision 与风险说明也不会绕过现有审批、
验证或人工发布门禁。

完整状态见 [`v0.7-release-audit.md`](v0.7-release-audit.md)。
