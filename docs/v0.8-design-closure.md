# V0.8 父子语义画布设计闭合

状态：已批准并进入实现；旧 V0.8 统一画布候选已被用户视觉反馈取代，不具备发布资格

实施基线：[`v0.8-parent-child-semantic-canvas-implementation-plan.md`](v0.8-parent-child-semantic-canvas-implementation-plan.md)

## 已闭合决策

### DC-0801：只有一套 Canvas Runtime 和两种模式

V0.8 不再把“全景查看 / 架构设计 Studio / 全景讲解”实现为三个并列图形表面。页面只有一个
Canvas World、一套几何、Camera 和 Selection：

- `read`：阅读正式事实和源码绑定的 Current Observation；
- `edit`：编辑隔离 Target Candidate，不直写 Current、Core 或业务源码。

讲解、进度、风险/决策、证据和动效属于阅读镜片，不是第三种模式、新页面或另一张图。

### DC-0802：架构主画布与模块逻辑子画布是两级语义导航

项目架构主画布显示 Layer/Container、Module、Connection 和 Resource。单击模块只选择；双击或键盘
Enter/Space 进入该模块的内部逻辑子画布。子画布只展开当前模块的内部处理，其他模块/资源仅以
紧凑外部引用卡出现，不泄漏它们的内部节点。面包屑/Back 恢复父画布离开前的相机与选择。

### DC-0803：Current 观察与 Target 设计严格分离

Current 模块内部逻辑来自 Codex 对项目源码的有界、瞬时归纳，固定为 `derived/inferred`，并绑定
Source Hash、Evidence Pin、Coverage、Producer 和 Information Gap。它是可过期的只读 Sidecar，不写 Core。

Target 是可编排的正式设计候选。首次编辑可从 Current Observation 复制起点，但不改变 Current 权威；
Source Drift 保留草稿，同时使 Formal Validation、Review 和 Proposal stale。

### DC-0804：多种图是同一语义场景的结构镜片

Module、Dependency/Data Flow、Deployment/Runtime、Sequence、Lifecycle 和 Evolution/Risk 不再对应六个割裂画布。
镜片切换保持场景身份、几何、相机和选择；必须新增 Resource/外部引用时才可重编译 Scene，仍不得挂载
第二套 Guided/Studio Runtime。

### DC-0805：讲解使用逐步展开的设计逻辑链

首屏只显示当前重点。模块/内部节点必须按“设计需求 → 设计原因 → 实现功能 → 系统角色 →
内部处理 → 外部交互 → 技术选型 → Evidence/Gap”形成完整逻辑。Risk 必须解释成因、触发条件、
可能结果、应对与剩余风险；Decision 必须解释为什么现在决策、选项代价、影响对象与未决条件。

### DC-0806：业务动效只播放显式轨迹

静态 Connection 不等于业务执行轨迹。播放只沿已验证 Business Flow/Event 绑定的原 Node/Edge Path 高亮，
禁止根据布局、名称或拓扑猜测顺序。速度、当前 Step、暂停、选择和 Reduced Motion 只是 Viewer State。

### DC-0807：Studio 层级和模块内部逻辑都是 Candidate Semantic

Layer 名称、顺序、父子关系，Module 语义，Logic Node/Edge、Loop 退出条件、Boundary Port 与外部 Binding
进入 Semantic Hash；坐标进入 Layout Hash；Camera、Selection、Explain/Playback 状态不进入两者。未绑定跨边界端口
可在 Candidate 中显示，但 Formal Proposal 必须 fail closed。

## 不变量

- Current、Target、Transition、Historical 不混合；Observed、Declared、Derived、Inferred、Unknown 不混淆。
- Core/Event/Source Observation → Model IR → View IR → Explain Pack → Renderer 保持单向投影。
- 画布不会从几何、文案或 AI 归纳自动制造 Runtime Call、Risk、Decision、Validation 或 Approval 事实。
- 正式变更仍经 Session CAS → Formal Validation → optional Agent Review → Proposal Freeze → 精确 Hash 批准 → Apply。
