## 发布范围

V0.6.0 候选在 V0.5.0 兼容基线上增加：

1. Evidence-bound Model IR、六类 single-scope View IR 与 Guided Multi-variant View Set；
2. Python、JavaScript/TypeScript、Java、Maven 与安全 Properties 的有界 Source Extraction；
3. 只产生 `pending_review` 候选、不会自动创建正式 Module 的 Source→Module Mapping；
4. Module、Dependency/Data Flow、Deployment/Runtime、Sequence、Lifecycle、Evolution/Risk 投影；
5. 离线 Single HTML 的 Search/Focus、Trace、Filter、Deep Link、Drawer、Pan/Zoom/Fit、主题与键盘路径；
6. Browser Evidence、immutable Candidate/Receipt、last-good 交付与 `verified_delivery.promote` Policy Adapter；
7. `event_head.recover` V0.5.1 内部里程碑能力随本次公开版本一并交付。

本版本不包含完整语言解析器、通用 Event Capture、Dataset/RAG/Eval Export、模型后训练、向量数据库、Agent
调度、云端协作或自动架构治理采纳。静态依赖不等于运行调用，package/file 不等于正式 Module，机器截图不等于
人工视觉接受。
