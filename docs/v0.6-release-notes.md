# Agent Project Panorama V0.6.0

V0.6.0 将项目全景从单一正式 Panorama 扩展为证据绑定、可重算、可交互的多视图架构交付，同时保持
V0.5 治理和 Schema 0.1/0.2 兼容。

## 新增能力

- Evidence-bound Model IR、六类 View IR 与 Guided Current/Target/Historical View Set；
- Python、JavaScript/TypeScript、Java、Maven 与安全 Properties 的有界 Source Extraction；
- 只产生 `pending_review` 候选、不会自动创建正式 Module 的 Source→Module Mapping；
- Module、Dependency/Data Flow、Deployment/Runtime、Sequence、Lifecycle、Evolution/Risk 投影；
- 离线 Single HTML 的 Search/Focus、Trace、Filter、Deep Link、Drawer、Pan/Zoom/Fit、主题与键盘路径；
- immutable Candidate/Receipt、Browser Evidence、last-good 事务和 `verified_delivery.promote` Policy Adapter；
- 纳入 V0.5.1 内部里程碑的 `event_head.recover` Policy Adapter。

## 验证

- 最终本地基线：408 passed，2 skipped；V0.6 聚焦 59 passed；
- Runtime Preflight：25 Schemas compatible，0 error；
- Controlled Orders、Spring PetClinic、Backstage slice 共 18 个真实浏览器 viewport；
- 0 node overlap、0 edge-through-node、0 side overflow、0 console error/warning；
- 三个精确代表 Artifact Hash 已获得独立人工视觉接受；
- 受控离线示例：[`examples/v0.6-multi-view-orders.html`](../examples/v0.6-multi-view-orders.html)。

## 明确边界

V0.6.0 不提供完整语言解析器、通用 Event Capture、Dataset/RAG/Eval Export、模型后训练、向量数据库、Agent
调度或云端协作。静态 import/dependency 不等于运行调用，file/package 不等于正式 Module，机器 Receipt 的
`visualReview=pending` 不等于人工接受；独立 Human Acceptance 使用外部精确 Hash 记录。

完整审计见 [`docs/v0.6-release-audit.md`](v0.6-release-audit.md)。
