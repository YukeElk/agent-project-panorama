## 发布范围

V0.7.0 在 V0.6.0 的证据绑定多视图架构交付之上增加：

1. 一份由 Panorama Core、Model IR、View IR 和 Guided View Set 确定性编译的 Explain Pack；
2. 六类 View Profile 的逐步讲解，以及 Decision、Transition、Evidence/Freshness、Verification Trace；
3. Codex 对话内、无网络、单根节点的交互 Fragment 与 Markdown 降级；
4. Panorama 原生 `<dialog>` 讲解器、图节点/边聚焦、章节/步骤导航和键盘路径；
5. Explain Pack 到 Renderer Bundle、Verified Delivery Candidate 的语义与字节 Hash 绑定；
6. 保持单一 Skill、Codex 终端与 V0.6 Core/Model/View IR 合同兼容。

本版本不复制或硬依赖 Visualize 插件，不引入云端后端、通用 Agent 平台、Dataset/RAG/Eval Export、模型后训练，
也不将静态 Dependency 提升为运行时调用。讲解只允许引用 `bound_fact`、`information_gap` 或
`navigation` Claim；Viewer State 不进入 Semantic Hash。
