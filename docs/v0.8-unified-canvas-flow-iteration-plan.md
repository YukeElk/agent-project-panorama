# V0.8 同页讲解与业务流程动效迭代方案

## 迭代目标

V0.8 将 V0.7 的独立讲解页面收回正式 Panorama：控制台、系统、演进、Evidence Inspector、Studio、多视图讲解和业务流程演示共享同一交付页面与事实边界。

## 工作包

1. 新增显式 `businessFlows` Core 契约、跨引用与方向校验。
2. 将模块讲解改为“设计需求 → 设计原因 → 实现功能 → 系统角色 → 交互方式 → 技术选型 → 决策与风险”逻辑链。
3. Explain Pack 新增确定性 `playbackScenarios`，精确绑定 Core/View/Node/Edge。
4. 取消 V0.7 iframe/dialog Host，改为 System 页内 `全景讲解` 画布模式。
5. 节点单击直接查看详情；讲解、节点和流程使用同一右侧 Rail，不再弹出第二页面。
6. 加入用户启动、有限、可暂停、可重放、可调速且支持 Reduced Motion 的轨迹动效。
7. 将 Studio 层级从固定展示带升级为 Candidate Semantic：支持新增、重命名、排序、父子关系和安全删除；模块和数据流继续可编辑。
8. 保留原有信息于渐进式“深入证据与治理信息”，避免展示层丢失。

## 验收矩阵

- 六类 View 均有整图和节点讲解；空 View 清空旧上下文。
- 风险包含成因、影响、结果和应对措施；决策包含触发原因、选项和可能结果。
- 不含 iframe、data URL 或讲解 Modal。
- Business Flow 错序、断链、反向连接、范围冲突和重复默认流程必须失败。
- 动画不自动播放，完成后停止；Reduced Motion、隐藏页和打印行为可验证。
- Studio 层级语义进入 Semantic Hash，`layoutHeight` 等纯布局状态不进入。
- 旧版控制台、系统、演进、Evidence Inspector 与 Studio 回归测试继续通过。

## 发布边界

完成实现与验证不等于发布。V0.8 在形成候选、代表项目视觉验收和正式发布评审前保持未发布状态。
