# Agent Project Panorama V0.8.0

状态：验收后修正已实现；新的浏览器证据与人工视觉接受待完成；发布阻断

V0.8 将全景查看、逐步讲解和架构设计 Studio 收敛到同一张语义画布，并引入“项目主画布 → 模块子画布”的两级阅读与编辑模型。

## 本版能力

- 单一画布、双模式：阅读模式负责源码事实、风险、决策与业务流讲解；编辑模式在同一空间内编排候选架构，不覆盖正式事实。
- 六类项目级视图：模块、依赖/数据流、部署/运行时、时序、生命周期、演进/风险。
- 模块子画布：双击模块进入内部实现逻辑，只展开当前模块；跨模块交互以边界端口和外部模块引用卡片呈现。
- 中文主扫描层：架构层级、模块、关系、状态及讲解优先显示中文名称，稳定 ID 和英文技术名保留为辅助信息。
- 完整解释链：设计需求、设计原因、实现功能、系统角色、交互方式、技术选型、证据边界与信息缺口。
- 风险与决策讲解：覆盖产生原因、影响结果、应对措施，以及决策动因、备选项和代价。
- 业务流动效：依据显式业务流程和数据流逐步播放，支持播放、暂停、单步、定位和减弱动态效果。
- 画布交互：空白区域拖拽平移、滚轮缩放、Fit、节点单击查看、双击下钻和键盘操作。
