## 已知限制

- Receipt 内容仍是外部声明；Panorama 验证格式、绑定与映射，不证明 producer 或执行环境可信。
- Isolation 只披露 `enforced / not_enforced / not_executed / unknown`，不会猜测或提升状态。
- P2 不保存完整测试日志、项目源码、环境变量或凭据，也不提供测试运行、沙箱或自动选优。
- Panorama Schema 0.1 只能通过 Reference extension 投影 Receipt；富结构历史需另行批准 SF-27。
- 当前本机不能创建符号链接，相关用例将在 Linux CI 实际执行；本地已有路径逃逸与 Bridge
  reparse/junction 回归未跳过。

## 发布门禁

1. 提交发布候选分支并保持工作树干净。
2. 推送后要求 GitHub Actions 全部通过，包括 Linux 符号链接 Receipt 用例。
3. 审查 Release diff 只包含 V0.4 允许范围、独立 Receipt Schema 和生成后的 Reference HTML。
4. GitHub Release 说明必须保留 `Verification Receipt Adapter = Experimental` 与上述信任边界。
5. 远程 CI 未通过前不得创建最终 tag 或 Release。
