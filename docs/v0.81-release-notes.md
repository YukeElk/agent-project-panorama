# Agent Project Panorama V0.81.0

V0.81 发布 V0.8 父子语义画布并关闭验收后发现的编辑与信息架构问题。查看和讲解属于同一个阅读模式，Studio
属于同一画布的编辑模式；项目主画布可下钻到模块内部逻辑子画布。

## 主要能力

- 唯一 Canvas Runtime 与 `read | edit` 双模式，自由平移、缩放、Fit、单击详情和双击下钻；
- 六类项目视图：模块、依赖/数据流、部署/运行时、时序、生命周期、演进/风险；
- 架构层级、功能模块和模块内部逻辑两级语义画布；跨模块交互在子画布中保持为外部引用；
- 中文主扫描层，以及“设计需求 → 原因 → 功能 → 系统角色 → 交互 → 技术选型 → 风险/决策”的完整解释链；
- 风险成因、影响、可能结果和应对措施讲解；决策动因、候选项、代价和结果讲解；
- 基于正式 Business Flow/Connection 的有限系统动效演示；
- 编辑既有模块、拖动后连线实时重算、跨层拖动吸附并更新候选层级归属；
- 控制台改为当前阶段决策驾驶舱，完整需求及其阶段、模块、版本迁移和交付证据链归入演进页；原始 Trace 默认
  折叠为技术诊断。

## 验证摘要

- 全量自动化：`490 passed, 2 skipped`；两个 skip 为既有 Windows 符号链接权限覆盖；
- Skill Creator quick validation、Renderer JavaScript、URL Sanitizer、候选可执行 Script 语法和
  `git diff --check` 通过；
- 代表制品：`PVD-2E32A984B6355D411AF96825`，SHA-256
  `b1d28b90a964d3b8ac647617bcc2bedaef98e714f04320ca67120612043efc52`，`966230` bytes；
- 仓库参考页面 `examples/v0.8-unified-canvas-reference.html` 与该 PVD 逐字节一致；
- Verified Delivery 的 Model/View、Geometry、Privacy、Offline Security Gate 为 `passed`。

## 已知边界

- 新修复字节没有新的 Browser/Viewport/Console 自动化证据；Receipt 如实记录 `browser.status=not_provided`，
  机器 `visualReview=pending`。用户已通过普通自然语言发布批准接受唯一冻结候选；这不会冒充机器浏览器验证。
- 模块内部 Current Logic 只来自有界源码观察与证据绑定；证据不足时显示信息缺口。
- Studio 仍输出隔离 Candidate；正式 Core 变更继续执行 Proposal/Approval/Apply。
- Requirement Realization 与可重建 Architecture Snapshot 属于后续 P1，V0.81 只沿正式 ID 生成标注为“推导”的
  只读需求演进投影。
- Dataset/RAG/Eval Export、通用 Agent 平台和完整多语言源码架构恢复不属于本版本。
