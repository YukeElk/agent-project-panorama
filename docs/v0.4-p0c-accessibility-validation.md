# V0.4 P0C Accessibility Validation

日期：2026-08-13

范围：Architecture Studio 的键盘操作、焦点闭环、数据流文本替代、触控目标与 840px 响应式分段面板。
本报告记录 WCAG 相关实现证据，不是完整 WCAG 认证。

- 全量测试：`246 passed in 73.27s`。
- `tests/test_v040_studio_accessibility.py` 覆盖候选 Tab 键盘模型、节点布局键盘操作、连线文本替代、
  Drawer/Dialog 焦点生命周期、移动端面板与持续错误提示。
- 既有 Architecture Studio、Evidence Inspector、Schema、Proposal/Approval/Apply 与 Presentation
  保护测试继续运行。
- Renderer JavaScript 使用 Node `--check` 验证语法；Reference HTML 重新生成后验证 Payload 与
  Presentation Hash。

## 浏览器检查

入口：受保护的 `127.0.0.1` Studio Bridge launcher → capability 验证 → Panorama document →
`系统 → 架构设计 Studio`。

- 页面身份、非空内容、无框架错误层：通过。
- 候选 Tab 暴露为 `tablist/tab/tabpanel`；单候选方向键保持当前 Tab：通过。
- Project Console 使用 `Alt + ArrowRight` 从 `x=145` 移至 `x=155`；Layout Operation `0 → 1`，
  Semantic Operation 保持 `0`：通过。
- 克隆 Dialog 打开后候选名称输入框获得焦点；取消后焦点返回“克隆”触发按钮：通过。
- 数据流列表暴露 6 条文本等价项；SVG 本体对辅助技术隐藏：通过。
- Console error/warning：0。

## 边界

- 没有声明完整 WCAG 2.x 合规或认证。
- P0C 不修改 Panorama Schema、`project-panorama-data` 或治理状态；所有布局移动仍停留在隔离 Session。
- 浏览器视口能力未改变当前内置浏览器窗口尺寸；840px 响应式分段行为由静态合同测试覆盖，最终发布前
  仍应在常见实体设备浏览器做一次手工抽查。
